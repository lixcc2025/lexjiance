# 云端 AI 识别接口（v1）

本机只做不用模型的检测。AI 合成语音、AI 生成画面、隐形水印要模型，放在服务器上：可以是我们的云服务，也可以是法院、检察院内网的一台服务器。桌面端在「设置 → 云端 AI 识别」填地址和令牌。

客户端实现：`desktop/electron/main/cloud.ts`（请求）、`desktop/shared/cloud-protocol.ts`（结果清洗和合并）。模拟服务器：`tools/mock_cloud.py`。

## 隐私约定

- 客户端**不上传原文件**，只上传 16kHz 单声道 FLAC 音轨和抽帧（每秒一帧，最多 120 张，长边 512 的 JPEG）
- 服务器识别完应**立即删除**上传内容，不留存、不用于训练
- 生产环境必须用 HTTPS；内网部署可用 HTTP

## 鉴权

请求头 `Authorization: Bearer <令牌>`（客户端设置了令牌才带）。令牌不对返回 401 或 403，客户端提示「访问令牌不对或已过期」。

## GET /v1/health

测试连接用。

```json
{ "ok": true, "version": "1.2.0", "models": ["voice-xlsr-zh-2026q4", "video-clip-2026q3"] }
```

## POST /v1/detect

`multipart/form-data`：

| 字段 | 内容 |
|---|---|
| `meta` | JSON，见下 |
| `audio` | `audio.flac`，没有声音时不传 |
| `frames` | 多个，`f0000.jpg`、`f0001.jpg`……，没有画面时不传 |

`meta`：

```json
{
  "api": "v1",
  "client": { "name": "avdetect", "version": "0.5.0", "platform": "win32" },
  "duration": 25.21,
  "sample_rate": 16000,
  "has_audio": true,
  "frames": [{ "t": 0.5, "name": "f0000.jpg" }, { "t": 1.5, "name": "f0001.jpg" }]
}
```

`frames[].t` 是这一帧在原文件里的时间（秒）。

返回 JSON：

```json
{
  "detectors": [
    { "name": "ai_voice", "ok": true, "seconds": 3.2 },
    { "name": "ai_video", "ok": true, "skipped": "没有画面" },
    { "name": "watermark", "ok": false, "error": "模型加载失败" }
  ],
  "findings": [
    {
      "detector": "ai_voice",
      "category": "ai",
      "severity": "high",
      "modality": "audio",
      "title": "这一段声音疑似 AI 合成",
      "detail": "为什么可疑、依据是什么（给律师看的话）",
      "start": 8.4,
      "end": 12.0,
      "evidence": { "合成概率": 0.97, "模型": "voice-xlsr-zh-2026q4" }
    }
  ]
}
```

- `detectors[].name`：`ai_voice`（AI 合成语音）、`ai_video`（AI 生成画面）、`watermark`（隐形水印）。没返回的，客户端显示「服务器未返回」
- `findings` 格式和本机检测一样（`engine/avengine/models.py` 的 Finding）：
  - `category`：`ai` / `edit` / `source`
  - `severity`：`info` / `low` / `medium` / `high`
  - `start`、`end`：原文件里的秒数，没有位置填 `null`
- 客户端会清洗返回内容：类别、等级不认识的疑点丢掉；时间限制在文件时长内；最多取 500 条

## 结论怎么算

客户端把云端疑点和本机疑点合在一起，按同一套规则重算两项结论（`shared/verdict.ts`）：有 high 是「高度可疑」，有 low / medium 是「有疑点」。只要有一个云端检测项正常跑完，AI 结论才可能是「未发现」；云端没跑时是「无法判断」。

## 超时

健康检查 8 秒；识别 15 分钟（含上传）。
