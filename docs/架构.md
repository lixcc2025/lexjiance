# 架构

## 定位

律师、法院、检察院把视频、音频放进软件，判断**是否 AI 生成**、**有没有剪辑痕迹**，给出疑点位置（几分几秒）和疑点特征。不出正式报告。桌面软件，**主要是 Windows**，也能在 macOS 上跑。

- **本机**：不用模型的检测（元数据、封装结构、声音剪辑痕迹），离线、几秒出结果
- **云端（可选）**：要 AI 模型的检测（合成语音、AI 画面、水印）放在服务器上，律师的电脑跑不动模型。可以是我们的服务，也可以是单位内网服务器。只上传提取的音轨和抽帧，不传原文件

## 检测项

| 位置 | 名字 | 查什么 | 用模型 |
|---|---|---|---|
| 本机 | `metadata` | 国标 AI 隐式标识（字段拆开显示）、元数据里的 AI 工具名、C2PA 有无、编辑软件、拍摄设备、创建时间 | 否 |
| 本机 | `structure` | 时间戳断档、不在节奏上的关键帧、音画时长差 | 否 |
| 本机 | `audio_splice` | 数字静音、底噪突变、频带突变（大量数字静音按通话软件静音压缩处理） | 否 |
| 云端 | `ai_voice` | AI 合成语音（声音克隆、TTS） | 是 |
| 云端 | `ai_video` | AI 生成画面（文生视频、换脸） | 是 |
| 云端 | `watermark` | AudioSeal 等隐形水印 | 是 |

**加一个本机检测项**：在 `engine/avengine/detectors/` 写一个 `Detector` 子类（`name`、`title`、`desc`、`needs`、`run()`），在 `detectors/__init__.py` 的 `ALL` 里登记。不适用时抛 `Skip("原因")`；出错不影响其他项。界面自动出现，不用改桌面端。

**加一个云端检测项**：服务器按 `docs/云端接口.md` 返回；桌面端在 `shared/cloud-protocol.ts` 的 `CLOUD_DETECTORS` 加一行（名字、标题、说明）。

## 数据流

```
页面 window.avd.analyze(文件)
  → ipc → analysis.startAnalysis
      → engine: python -m avengine analyze 文件 --jsonl   逐行：progress / finding / detector / result
      → cloud.withCloud（启用时）: extract → POST /v1/detect → sanitize → mergeCloud（重算结论）
  → engine-event 事件推回页面（useAnalysis 接收）
同时 window.avd.preview(文件) → preview.getPreview（缓存）→ 时间轴素材
```

## 结论规则

AI 生成、剪辑痕迹分别按该类疑点的最高严重程度：有 high →「高度可疑」，有 low / medium →「有疑点」，没有 →「未发现」。AI 生成另有一条：云端模型没跑时是「无法判断」，不说「未发现」。界面固定提示：结果是辅助判断的线索，不是鉴定结论。

## 安全

- 页面没有 Node 权限（contextIsolation、sandbox），只能通过 `window.avd` 调有限的接口；不能打开新窗口、不能跳外部网址
- `media://` 只放行用户打开过的文件和预览素材目录
- 云端令牌用系统加密存（Windows DPAPI / macOS 钥匙串），不发给页面
- 云端返回的结果先清洗再用（类别 / 等级不认识的丢掉，时间限制在时长内）

## 开发

```bash
# 引擎
cd engine && python3 -m venv .venv && .venv/bin/pip install numpy
.venv/bin/python -m unittest -v                       # 18 项
.venv/bin/python -m avengine analyze 某文件.mp4

# 桌面端
cd desktop && npm install
npm run dev                                            # 开发运行（自动用 engine/.venv 的 Python）
npm run check                                          # 类型检查 + 单元测试
python3 ../tools/mock_cloud.py                         # 模拟云端服务器，设置里填 http://127.0.0.1:8765

# 开发用环境变量
AVD_PLATFORM=win32       在别的系统上模拟 Windows 窗口样式
AVD_WINDOW_SIZE=1280x720 固定窗口大小（检查小屏布局）
AVD_SNAPSHOT=out.png     启动后截窗口图（配合 AVD_SNAPSHOT_DELAY、AVD_SNAPSHOT_JS）
AVENGINE_PYTHON          指定 Python
```

打包见 `docs/打包.md`。
