# 架构

## 定位

律师、法院、检察院把视频、音频放进软件，软件判断**是否 AI 生成**、**有没有剪辑痕迹**，给出疑点位置（几分几秒）和疑点特征。
不出正式报告。独立桌面软件，**全程离线**，文件不上传（法院、检察院多在内网）。

## 组成

```
avdetect/
├── desktop/      桌面端：Electron + Vue 3 + TypeScript（electron-vite）
│   ├── electron/main/     主进程：窗口、选文件、启动检测引擎、media:// 本地回放协议
│   ├── electron/preload/  给页面暴露 window.avd（选文件、检测、取消、事件）
│   └── src/               页面：拖入文件 → 进度 → 两项结论 + 疑点列表 + 时间轴，点疑点跳到对应位置回放
├── engine/       检测引擎：Python（avengine）
│   ├── avengine/probe.py        调 ffprobe 读结构
│   ├── avengine/pipeline.py     逐个跑检测项、汇总结论
│   ├── avengine/detectors/      检测项（一个文件一类）
│   └── tests/                   用 ffmpeg 现场造样本测
└── docs/
```

桌面端和引擎之间：主进程起子进程 `python -m avengine analyze <文件> --jsonl`，引擎每行输出一个 JSON 事件：

| type | 内容 |
|---|---|
| `progress` | `pct`（0~1）、`stage`（正在做什么） |
| `finding` | 一条疑点（检测过程中陆续出来） |
| `detector` | 一个检测项跑完：完成 / 未运行（原因）/ 出错 |
| `result` | 最终结果：媒体信息、两项结论、全部疑点、检测项状态 |
| `error` | 文件读不了等 |

引擎也能单独当命令行用：`python -m avengine analyze 文件`（文字）、`--json`。

## 疑点（Finding）

| 字段 | 说明 |
|---|---|
| category | `ai` AI 生成迹象 / `edit` 剪辑痕迹 / `source` 来源信息（设备、软件、转码，本身不算疑点） |
| severity | `info` 说明 / `low` 轻微 / `medium` 可疑 / `high` 高度可疑 |
| title / detail | 发现了什么 / 为什么可疑、还有哪些正常解释 |
| start / end | 疑点位置（秒），没有位置的为空 |
| evidence | 原始数据，方便复核 |

## 结论规则（pipeline._verdict）

- AI 生成：有 high → 高度可疑；有 low / medium → 有疑点；什么都没有且**模型没跑** → 无法判断（不说「未发现」，避免误导）；模型跑了也没发现 → 未发现
- 剪辑痕迹：同样按最高严重程度，没有 → 未发现（注明重新编码的剪辑可能查不出）
- 界面底部固定提示：检测结果是辅助判断的线索，不是鉴定结论

## 检测项

| 名字 | 内容 | 状态 |
|---|---|---|
| `metadata` | 国标 AI 隐式标识、元数据里的 AI 工具名、C2PA 有无、编辑软件、拍摄设备、创建时间 | v0.1 已做 |
| `structure` | 时间戳断档、不在节奏上的关键帧、音画时长差 | v0.1 已做 |
| `audio_splice` | 底噪突变、电网频率断续、数字静音、频谱断层 | 下一步 |
| `watermark` | AudioSeal 等隐形水印 | 待做 |
| `ai_voice` | AI 合成语音（模型，分段打分出可疑时间段） | 待定方案 |
| `ai_video` | AI 生成画面 / 换脸（模型，抽帧） | 待定方案 |

新加检测项：在 `engine/avengine/detectors/` 写一个 `Detector` 子类，加进 `__init__.py` 的 `ALL`。不适用或缺条件时抛 `Skip("原因")`。
一个检测项出错不影响其他项。

## 打包（以后做）

和律衡一样，安装包里带 Python 运行时（`resources/python`）、引擎（`resources/engine`）、ffmpeg / ffprobe，用户不用装任何东西。
模型文件放 `resources/models`，用 ONNX Runtime 在 CPU 上跑。Windows、Mac 两个平台。

## 开发

```bash
cd engine && python3 -m unittest -v              # 引擎测试（要 ffmpeg）
python3 -m avengine analyze 某文件.mp4             # 命令行试
cd desktop && npm install && npm run dev          # 桌面端（开发时用系统 python3，可用 AVENGINE_PYTHON 指定）
npm run build && npm run typecheck
```
