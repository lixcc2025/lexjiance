# 打包

## Windows 安装包（主要）

在 Windows 电脑上（Win10 / Win11，x64）：

1. 装 [Node.js 22 或更新](https://nodejs.org/)（安装时勾选自动装 npm）和 Git
2. 拿到代码后：

```powershell
cd avdetect\desktop
npm install
npm run dist:win
```

`dist:win` 做三件事：

1. `node scripts/prepare-runtime.mjs win32-x64`：按 `build/runtime.json` 下载并校验（SHA256）
   - Python 3.11.9 嵌入版（python.org）
   - numpy 2.1.3（PyPI）
   - FFmpeg 8.1 LGPL 动态链接版（BtbN/FFmpeg-Builds）
   - 把引擎 `../engine/avengine` 复制进去

   组装到 `build/runtime/win32-x64/`，然后**自检**：跑一次引擎检测一段 3 秒的正弦波，必须全部通过。下载的文件缓存在 `build/cache/`，再打包不用重新下载（要更新加 `--refresh`）。
2. `electron-vite build`：编译界面和主进程
3. `electron-builder --win --x64`：生成 `release/avdetect-<版本>-win-x64-setup.exe`

安装包：可选安装位置、建桌面和开始菜单快捷方式、中文安装界面；卸载不删用户设置和检测记录。

### 代码签名

没有签名时，Windows 会提示「未知发布者」（SmartScreen）。有代码签名证书后，打包前设置环境变量即可，不用改配置：

```powershell
$env:CSC_LINK="C:\path\证书.pfx"; $env:CSC_KEY_PASSWORD="密码"
npm run dist:win
```

### 常见问题

- 下载慢或失败：重跑即可，已下载的会复用；或者手动把文件放进 `build/cache/`（文件名和 `runtime.json` 里的一样），脚本会校验后使用
- 杀毒软件拦截 `python.exe`、`ffmpeg.exe`：签名后会好很多；内网可把安装目录加白名单
- 想固定 FFmpeg 版本：`runtime.json` 里的地址是 8.1 分支的最新构建，保留 `build/cache/` 里的 zip 就不会变

## 不想自己打包：用 CI 打好的

每次往 GitHub 推代码，CI 会在 GitHub 的 Windows 机器上跑一遍 `npm run dist:win`（包括运行时自检），打好的安装包保留 14 天：

1. 打开 <https://github.com/lixcc2025/lexjiance/actions>，点最新一次绿色的运行
2. 页面最下面「Artifacts」里的 `windows-installer`，下载（要登录 GitHub），解压得到 `avdetect-<版本>-win-x64-setup.exe`

## macOS（次要）

```bash
cd avdetect/desktop
npm install
FFMPEG_DIR=/path/to/ffmpeg所在目录 npm run dist:mac
```

- Python 用 python-build-standalone 3.11.18，numpy 同上
- macOS 没有固定的 LGPL 官方构建，用 `FFMPEG_DIR` 指向自己准备的 `ffmpeg`、`ffprobe`（分发前确认许可证）
- 公证（notarize）前要给 `Contents/Resources/python/`、`ffmpeg/` 里的所有二进制签名，开 hardened runtime；没签名的包只能自己电脑上用（右键 → 打开）

## 包里有什么

```
安装目录/
├── avdetect.exe
└── resources/
    ├── app.asar          界面和主进程
    ├── engine/avengine/  检测引擎（Python 源码）
    ├── python/           Python 运行时 + numpy（python311._pth 里加了 Lib\site-packages、..\engine）
    ├── ffmpeg/           ffmpeg.exe、ffprobe.exe 和几个 dll
    └── licenses/         第三方许可证（Python PSF、NumPy BSD、FFmpeg LGPL）
```

用户数据（设置、日志）在 `%APPDATA%\avdetect-desktop\`；预览缓存在系统临时目录 `avdetect-preview\`。

## 升级依赖版本

改 `desktop/build/runtime.json`：

- Python：换 `url`，用新文件的 SHA256 更新 `sha256`（PowerShell：`Get-FileHash 文件 -Algorithm SHA256`）；`pth`、`wheelTag` 跟着 Python 版本改（比如 3.12 是 `python312._pth`、`cp312-cp312-win_amd64`）
- numpy：改 `numpy` 版本号，脚本从 PyPI 取对应的包和校验值
- FFmpeg：换 `url`，校验值从同一发布的 `checksums.sha256` 取；**只能用 lgpl 版**（gpl 版不能随闭源软件分发）
