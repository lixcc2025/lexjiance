# AI 识别模型：方案和接入步骤

服务端的代码（推理、切窗、定位、评测）已经写好，**缺的是模型本身**。这份文档说明每个检测项用什么模型、怎么准备、怎么接进来、怎么判断准不准。

> 云端开发环境不能下载和运行模型，所以下面「训练 / 导出」的步骤要在有显卡的机器上做。服务端用测试用的假模型把整条流程测通了。

## 总原则

1. **先建测试集，再选模型、定阈值**：没有中文测试集，说不清准不准。测试集要覆盖律师实际碰到的情况：手机录音、微信语音（AMR / 转码）、电话录音、翻录、压缩
2. **许可证必须允许商用**：CC BY-NC、「仅研究用途」的权重不能用；只能借鉴它们的代码思路自己训
3. **底座 + 小分类头**：用公开的自监督 / 视觉底座模型提特征，只训练最后一层分类头，几个小时一张卡就够；主要成本在数据
4. **阈值按法律场景定**：误报（把真录音说成 AI）代价高，「可疑」阈值取误报 5% 处，「高度可疑」取误报 1% 处

## 各检测项

### AI 合成语音（ai_voice）—— 最优先

| | |
|---|---|
| 做法 | 自监督语音底座（XLS-R 300M 或 WavLM）提特征 + AASIST / 线性分类头 |
| 参考代码 | [TakHemlata/SSL_Anti-spoofing](https://github.com/TakHemlata/SSL_Anti-spoofing)（MIT） |
| 底座许可 | XLS-R（fairseq，MIT）、WavLM（MIT）——商用前再核对一次 |
| 训练数据 | 真：公开中文语音（选可商用许可的）+ 自录的手机、微信、电话录音；假：用国内主流语音合成 / 声音克隆（豆包、海螺、Fish Audio、CosyVoice、GPT-SoVITS 等）对同样文本批量生成，**每种都过一遍微信转码、电话编码、翻录** |
| 输入输出 | 16kHz、4 秒窗、2 秒步长；输出两类 logit（真 / 假） |
| model.json | `models/_examples/ai_voice.model.json`（normalize 用 zscore，和底座训练时一致） |

导出 ONNX（PyTorch，示意）：

```python
model.eval()
dummy = torch.zeros(1, 64000)                       # 4 秒 × 16k
torch.onnx.export(model, dummy, "model.onnx", input_names=["audio"], output_names=["logits"],
                  dynamic_axes={"audio": {0: "N"}, "logits": {0: "N"}}, opset_version=17)
```

### AI 生成画面（ai_video）

| | |
|---|---|
| 做法 | CLIP ViT-L/14 图像特征 + 线性分类头（逐帧打分，服务端合并成时间段） |
| 参考 | [WisconsinAIVision/UniversalFakeDetect](https://github.com/WisconsinAIVision/UniversalFakeDetect)（MIT）；文生视频专门的 [DeMamba](https://github.com/chenhaoxing/DeMamba)、[NSG-VD](https://github.com/ZSHsh98/NSG-VD)（Apache-2.0）可作为第二阶段 |
| 训练数据 | 真：手机、监控、执法记录仪画面；假：可灵、即梦、海螺、Sora、Veo 等生成的视频抽帧；同样过压缩、缩放、翻拍 |
| 输入输出 | 224×224 中心裁剪、CLIP 均值方差、NCHW；输出一个 logit |
| model.json | `models/_examples/ai_video.model.json` |
| 换脸 | 换脸检测的好权重多是禁商用的（DeepfakeBench 等），第二阶段单独做：人脸检测（OpenCV YuNet，MIT）裁人脸再分类 |

### 隐形水印（watermark）

| | |
|---|---|
| 做法 | [facebookresearch/audioseal](https://github.com/facebookresearch/audioseal) 的检测器（MIT），导出 ONNX |
| 局限 | 只认 AudioSeal 水印；国内工具的水印各家不公开，靠元数据里的国标隐式标识（本机已做） |
| model.json | `models/_examples/watermark.model.json`（输出每个窗口有水印的概率） |

## 接入步骤

1. 训练 / 导出得到 `model.onnx`，按模板写 `model.json`，放到服务器的 `models/<名字>/`
2. `python -m avserver models` 确认加载成功（显示用的是 CUDA 还是 CPU）
3. 用测试集评测：

   ```bash
   python -m avserver evaluate 测试集 --detector ai_voice --out 评测-语音.md
   ```

   测试集目录：`测试集/real/**`（真实）、`测试集/fake/<生成工具>/**`（AI 生成，按工具分目录）。
   报告给出 AUC、等错误率、误报 1% / 5% 时的阈值和检出率、**按生成工具**分的检出率（哪种工具认不出一目了然）
4. 把建议阈值写回 `model.json` 的 `thresholds`，重启服务
5. 每出一种新的生成工具：补一批样本进测试集 → 评测 → 检出率不够就加进训练数据重训分类头

## 建议的第一步（不用写代码）

先整理一个**小测试集**，几百条就够：

- real：手机录音、微信语音、电话录音各几十条（不同人、不同环境）
- fake：豆包、海螺、Fish Audio、CosyVoice、GPT-SoVITS 各几十条，其中一部分发一遍微信再存下来

有了它，任何候选模型拿来跑一遍评测，准不准、对哪种工具不行，马上就清楚。
