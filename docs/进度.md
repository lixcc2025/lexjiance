# 进度

## 2026-11-25 v0.1 框架

- 项目结构：桌面端（Electron + Vue 3 + TS）+ Python 检测引擎，逐行 JSON 事件通信
- 引擎：检测项接口、流水线、两项结论（AI 生成 / 剪辑痕迹）、命令行
- 已实现两个不靠模型的检测项：
  - 元数据：国标 AI 隐式标识、AI 工具名（可灵、即梦、Sora 等）、C2PA 有无、编辑软件、拍摄设备
  - 封装结构：时间戳断档（给出位置）、不在节奏上的关键帧、音画时长差
- 占位：声音剪辑痕迹、隐形水印、AI 语音、AI 视频（界面显示「未运行」和原因）
- 界面：拖入 / 选择文件、进度、两项结论、疑点列表、时间轴标疑点、点疑点跳到前 1 秒回放；支持带文件启动
- 测试：引擎 8 个（ffmpeg 现场造样本），桌面端构建和类型检查通过，云端虚拟屏幕里跑通整条链路
- GitHub 调研：`docs/开源调研.md`

## 2026-11-25 v0.2 界面改版

- 首页：拖放区（注明本机检测、文件不离开电脑）、三项能力说明、最近检测（本机保存 20 条，点一下重新检测）
- 检测中：检测项逐条显示进度（转圈 / 完成 / 未运行 / 出错），已发现的疑点实时出现，可取消
- 结果页：文件信息条（格式、时长、分辨率、编码、大小）；「AI 生成」「剪辑痕迹」两张结论卡；
  播放器下方是声音波形，疑点区间标在波形上，点疑点或波形跳转；疑点按「全部疑点 / AI 生成 / 剪辑痕迹 / 来源信息」分页签，
  展开看说明和依据表格；检测项出结果后收成一行摘要；所在文件夹、重新检测、检测其他文件；拖文件进窗口直接换
- 回放协议 media:// 改成标准协议并支持分段读取（Range）：大视频、索引在文件末尾的 MP4 都能播、能拖进度（原来大一点的视频播不了）
- 引擎：检测项分成短标题 + 一句说明，`detectors --json` 给界面用；依据字段带单位

## 2026-11-25 v0.3 界面重做（Mac 真机）

- 窗口：macOS 标题栏融进窗口、红绿灯嵌在侧栏，侧栏用系统半透明材质；中文应用菜单（⌘O 打开、⌘C/⌘V/⌘Q）；其他平台无菜单栏
- 主题：深色（默认设计）/ 浅色 / 自动跟随系统，侧栏底部切换；用 nativeTheme 切，侧栏材质和页面一起变
- 侧栏：品牌、新建检测、检测记录（两个圆点表示 AI / 剪辑结论）、引擎状态（本机就绪、云端 AI 未连接）
- 首页：扫描动画插画、拖放条、三项能力、离线说明
- 工作台：顶部文件信息条；左边播放器（自绘控制条：时间码、倍速、静音、全屏；音频用频谱图做背景）+ 多轨时间轴
  （画面缩略帧 / 波形 / 频谱 / 剪辑痕迹轨 / AI 生成轨，共用播放头，点击拖动定位，疑点区间在波形上着色，整文件的 AI 疑点画成斜纹条）；
  右边结论区（检测中是进度环 + 检测项流水线，完成后是两项结论卡）+ 疑点检查器（疑点 / 来源信息，展开看说明和依据，国标标识字段拆开显示）
- 快捷键：空格播放、←/→ 1 秒、Shift+←/→ 5 秒、Esc 取消选中、⌘O 打开
- 引擎新增 `preview` 命令：ffmpeg 流式生成波形（30 分钟录音约 6 秒）、频谱图、24 张缩略帧；桌面端按文件缓存
- media:// 加白名单：只放行打开过的文件和预览素材目录
- 开发：`tools/mac.sh sync` 同步到 Mac 并构建，`tools/mac.sh shot <名字> <文件> [延迟] [页面脚本]` 在 Mac 上截窗口图（capturePage，不用屏幕录制权限）
