# 云端 AI 识别服务：部署

服务代码在 `server/`（Python，FastAPI + ONNX Runtime）。桌面端在「设置 → 云端 AI 识别」填服务器地址和令牌即可使用，接口见 `docs/云端接口.md`。

## 两种部署

| | 我们的云服务（给律师） | 单位内网（法院、检察院） |
|---|---|---|
| 地址 | `https://ai.域名.com` | `http://10.x.x.x:8000` 或内部证书的 https |
| 证书 | Caddy 自动申请 | `tls internal`，或内网直接 http（客户端认内网地址，不会警告） |
| 联网 | 需要 | 不需要：镜像和模型离线拷进去 |

## 硬件

- **有显卡（推荐）**：NVIDIA T4 / L4 / A10（16~24GB 显存）。一段 10 分钟的录音，语音识别几秒到十几秒
- **只有 CPU**：能跑，慢很多（大模型可能接近录音时长）。`AVS_MAX_CONCURRENT` 设 1
- 内存 16GB 起；磁盘放模型（每个几百 MB 到 2GB）

## 步骤（Docker）

```bash
git clone https://github.com/lixcc2025/lexjiance.git && cd lexjiance/server
mkdir -p models data
# 1. 放模型：每个模型一个子目录（model.json + model.onnx），见 models/README.md
# 2. 生成访问令牌（只显示一次，发给使用单位填进软件）
docker compose run --rm avserver python -m avserver token add 某某律所
# 3. 启动（公网：先把域名解析到服务器）
AVS_DOMAIN=ai.你的域名.com docker compose up -d --build
# 4. 检查
docker compose exec avserver python -m avserver models
curl -H "Authorization: Bearer <令牌>" https://ai.你的域名.com/v1/health
```

显卡服务器：`docker-compose.yml` 里 `build` 改用 `Dockerfile.gpu`，取消 `deploy` 一段的注释；宿主机装 NVIDIA 驱动和 nvidia-container-toolkit。

## 内网离线部署

在能联网的机器上：

```bash
docker compose build && docker save avserver-avserver caddy:2 | gzip > avserver-镜像.tar.gz
```

把 `avserver-镜像.tar.gz`、`server/` 目录（含 `models/`）拷进内网服务器：

```bash
docker load < avserver-镜像.tar.gz
docker compose up -d          # Caddyfile 里改成 tls internal，或去掉 caddy 直接用 8000 端口
```

## 不用 Docker

```bash
cd server && python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 显卡用 requirements-gpu.txt
AVS_MODELS_DIR=models AVS_TOKENS_FILE=data/tokens.txt .venv/bin/python -m avserver serve --host 127.0.0.1 --port 8000
# 前面用 nginx / Caddy 做 HTTPS，request body 上限放到 300MB，读超时 20 分钟
```

## 配置（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `AVS_MODELS_DIR` | `models` | 模型目录 |
| `AVS_TOKENS_FILE` | `tokens.txt` | 令牌哈希文件 |
| `AVS_MAX_UPLOAD_MB` | 300 | 单次上传上限（一小时 16k FLAC 约 60MB，120 张帧约 10MB） |
| `AVS_MAX_FRAMES` | 200 | 单次最多帧数 |
| `AVS_MAX_AUDIO_SECONDS` | 14400 | 音轨最长 4 小时 |
| `AVS_MAX_CONCURRENT` | 2 | 同时识别几个请求 |
| `AVS_QUEUE_WAIT` | 120 | 排队超过几秒回「服务器忙」 |
| `AVS_DEVICE` | auto | auto / cpu / cuda |
| `AVS_THREADS` | 0 | CPU 推理线程，0 自动 |
| `AVS_ALLOW_NO_AUTH` | — | 设成 1 不校验令牌，**只用于本机测试** |

## 隐私和安全

- 上传的音轨和截图只在内存 / 请求临时目录里，处理完立刻删除；Docker 部署时 `/tmp` 是内存盘
- 日志只记请求编号、令牌名、有无音轨、帧数、疑点数、耗时，不记内容和文件名
- 令牌文件只存 SHA-256 哈希
- 上传大小边收边数，超了立即断开（防不带长度的大上传）；同时处理数有上限
- 关闭了 FastAPI 的 /docs、/openapi.json

## 运维

- 换模型：替换 `models/` 里的文件，`docker compose restart avserver`
- 吊销某单位：`python -m avserver token remove 某某律所`（立即生效，不用重启）
- 看日志：`docker compose logs -f avserver`
